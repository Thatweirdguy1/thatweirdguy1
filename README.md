## Selected work

### Quantum-Enhanced Retrieval-Augmented Generation
Experimental hybrid RAG pipeline combining classical retrieval with quantum-simulated kernel, Grover, and QAOA stages. The project emphasizes falsifiable evaluation, ablations, reproducibility, statistical testing, and honest negative results.

**Stack:** Python · FastAPI · Qiskit · FAISS · BM25 · NumPy · pytest

[View repository](https://github.com/Thatweirdguy1/Quantum-enhanced-RAG)

### Industrial Maintenance CMMS
Full-stack computerized maintenance management system for QR-based equipment workflows, predictive maintenance alerts, inventory burn-rate monitoring, automated reporting, and mobile-friendly technician workflows.

**Stack:** Next.js · React · Flask · SQLite · APScheduler · Nginx · DigitalOcean

[View repository](https://github.com/Thatweirdguy1/industrial-management-cmns)

### SegreSmart Waste Detector
Browser-side waste classification using ONNX Runtime Web, allowing image inference to run locally in the browser rather than sending images to a remote inference server.

**Stack:** ONNX Runtime Web · PyTorch · JavaScript · Tailwind CSS

[View repository](https://github.com/Thatweirdguy1/segresmart-waste-detector)
